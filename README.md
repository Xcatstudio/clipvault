# ClipVault

Лёгкий менеджер буфера обмена для Windows: история скопированного, закрепление, быстрые преобразования текста и авто-копирование выделения.

## Возможности

- История текста, картинок и файлов с поиском и фильтрами по типу.
- Закрепление важных записей (не удаляются при очистке истории).
- Быстрые преобразования текста: регистр, `snake_case`, `camelCase`, Base64, сортировка и удаление повторов строк и другое.
- Авто-копирование выделенного текста (UI Automation с запасным вариантом через `Ctrl+C`).
- Тёмный интерфейс с анимациями, горячие клавиши, автозапуск с Windows.
- Хранение данных локально, в папке `data` рядом с программой.

## Управление

- `Ctrl+Shift+V` (или клик по иконке в трее) — открыть историю.
- **Клик** по записи — скопировать в буфер (окно остаётся открытым).
- **Enter** — вставить запись в активное окно.
- **Правый клик** — меню: Скопировать / Закрепить / Удалить.
- `Tab` — сменить категорию, `Ctrl+P` — закрепить, `Del` — удалить.

## Сборка

Нужен .NET Framework 4.x (обычно уже есть в Windows 10/11).

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Иконка генерируется скриптом `make_icon.ps1` и встраивается в exe при сборке.

## Сайт

Исходники сайта-лендинга лежат в папке [`docs/`](docs/) и публикуются через GitHub Pages
(Settings → Pages → Branch: `main`, папка `/docs`).

## Приватность

Программа не отправляет данные в сеть. Вся история хранится локально в папке `data`.
Папка `data` исключена из репозитория (см. `.gitignore`) — личная история не публикуется.

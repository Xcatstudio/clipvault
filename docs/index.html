Закрепление

Быстрые преобразования

Регистр, snake_case, camelCase, Base64, сортировка строк, удаление повторов и многое другое.

Авто-копирование

Выделили текст — он сразу попал в историю. Работает в большинстве приложений через UI Automation.

Удобный выбор

Откройте историю по Ctrl+Shift+V. Клик — копировать, Enter — вставить, правый клик — меню действий.

🔒

Локально и приватно

Данные хранятся только у вас на компьютере, в папке data рядом с программой. Ничего в сеть.
